### Environment gotcha (cost time)

- `pnpm exec remotion still` dies with `Protocol error (Target.createTarget):
  Target closed`. Cause: the bundled `chrome-headless-shell` crashes in this
  environment. Fix: add `--chrome-mode=chrome-for-testing` (already downloaded).
- Rendering a loop of 7 stills in one bash command got killed by Security Center
  rules on the puppeteer temp profile (delete rules). Render stills one at a time.

### Decisions

- `VennDiagram` deliberately has no arrows. The "AI is software / software runs on
  hardware" arrows are scene-4 content, not diagram geometry — keep them in the
  scene so the shared component stays reusable.
- `LayerIcon` has `animate={false}` so a parent (e.g. `LayerStack`) can drive the
  entrance without double-animating.
- `Captions` takes an explicit `{text, from, to}[]` timeline. Real timings come
  from the recorded voiceover, not from guesses.
